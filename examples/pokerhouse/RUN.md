# Run the rendered example

Self-contained Vite + React + Tailwind v4 app that renders the two screens generated by the `ui-from-references` skill.

```bash
pnpm install
pnpm dev
```

Then open `http://localhost:5274/`. A small `c08 / c16` toggle at the top switches between the two screens.

## What this proves about the skill

- The locked `design-tokens.json` becomes a Tailwind v4 `@theme` block in `app/globals.css` — no other CSS file exists.
- Every visual decision (color, radius, font size, spacing) traces back to a token.
- Every icon comes from `lucide-react` and is in the skill's `icon-library/lucide-icons.json`.
- Every image asset is generated by `gpt-image-2` and lives in `public/assets/`.
- The screen .tsx files in `app/` are the exact same files generated during Phase 3 of the skill — no production touch-ups.

## Build for production

```bash
pnpm build
pnpm preview
```

Output goes to `dist/`. The Tailwind v4 build inlines only the classes actually used.
