## Conventions

- All component class names below are **logical names** (e.g. `Button / Primary`). The corresponding shadcn primitive name is in `[brackets]`.
- All colors/sizes are token references, not literals.
- Every interactive element MUST have visible `:hover`, `:focus-visible`, `:active`, and `:disabled` states. State styles default to:
  - `:hover` — token `accent.primary_pressed` (or 90% opacity if not defined)
  - `:focus-visible` — outline 2px `accent.primary`, offset 2px
  - `:active` — translate-y 1px (subtle press)
  - `:disabled` — opacity 0.5, cursor not-allowed
- Components MUST be RTL/LTR neutral. Use `start`/`end` in Tailwind instead of `left`/`right` where applicable.

## Buttons

### Button / Primary [Button]
- Token: `components.button.primary`
- Tailwind class set: `inline-flex items-center justify-center h-12 px-6 rounded-pill bg-accent-primary text-text-inverse font-bold text-body`
- Use for: main CTAs (one per screen typically)

### Button / Secondary [Button variant="outline"]
- Token: `components.button.secondary`
- Tailwind: `inline-flex items-center justify-center h-12 px-6 rounded-pill bg-bg-raised border border-border-subtle text-text-primary font-bold text-body`
- Use for: cancel, dismiss, alternative actions

### Button / Ghost [Button variant="ghost"]
- Tailwind: `inline-flex items-center justify-center h-12 px-6 rounded-pill text-text-secondary hover:bg-bg-raised hover:text-text-primary`
- Use for: tertiary actions in dense layouts

### Chip / Filter [Toggle]
- Tailwind active: `h-9 px-4 rounded-pill bg-accent-primary text-text-inverse text-caption font-bold`
- Tailwind inactive: `h-9 px-4 rounded-pill bg-bg-raised border border-border-subtle text-text-secondary text-caption`
- Use for: category filters, GameType pills, segmented controls

### Badge / Status [Badge]
- Variants: NEW (accent.primary bg), HOT (accent.warning bg), VIP (accent.warning bg w/ border)
- Tailwind: `inline-flex items-center px-2.5 py-1 rounded-md text-micro font-bold text-text-inverse`

## Cards

### Card / Promotion (custom composition)
- Tailwind frame: `rounded-card bg-bg-raised border border-accent-primary p-4 flex flex-col gap-1`
- Children:
  - Title: `text-body font-bold text-text-primary flex items-center gap-2`
  - Subtext: `text-caption text-text-secondary`
  - Action: `text-caption font-bold text-accent-primary`

### Card / List Row (custom composition)
- Tailwind frame: `rounded-md bg-bg-raised border border-border-subtle p-4 flex items-center gap-3`

### Card / Game Tile (custom composition)

- Children:
